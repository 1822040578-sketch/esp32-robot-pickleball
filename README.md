# ESP32 Robot Pickleball

# Overview
This project is a pickleball shooting robot using ESP32 for motor and servo control.

# Hardware Components
- ESP32
- Servo MG996R
- BTS7960 Motor Driver
- Relay Module
- 12V DC Motor
- Power Supply 12V

# Software
- Arduino IDE (ESP32 Core 2.3.6)
- WiFi Communication
- ESP-NOW Protocol

# Features
- Motor speed control
- Servo angle adjustment
- Wireless communication between 2 ESP32 boards
- Real-time system testing and calibration

# Project Status
Completed and tested in real environment.
